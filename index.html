The question

Chidamber & Kemerer (1994) proposed six design metrics for object-oriented classes: WMC (weighted methods), DIT (inheritance depth), NOC (number of children), CBO (coupling), RFC (response set) and LCOM (lack of cohesion). They checked them against measurement theory but never against real faults.

Research questionDo CK metrics predict faulty classes because of design, or because they track class size?

The studies in detail

Basili, Briand & Melo (1996)

Data
8 student teams built the same C++ system; 180 classes
Found
Five metrics predict fault-prone classes; DIT, RFC and CBO strongest. LCOM not significant. NOC worked in reverse. CK metrics beat code metrics (88% vs 83% completeness).
Limits
Student programmers, small systems, size not controlled.

El Emam et al. (2001)

SIZE CONTROLLED
Data
Ericsson C++ telecoms framework; 174 classes, 70 with field-failure faults
Found
WMC, CBO and RFC predict faults until class size is controlled. Then no metric does.
Limits
One system. Evanco (2003) argues size is not a valid confounder.

Subramanyam & Krishnan (2003)

SIZE CONTROLLED
Data
B2C e-commerce suite; 405 C++ and 301 Java classes
Found
After size control, WMC and CBO still explain defects in C++ but not Java. Deeper inheritance meant fewer defects.
Limits
Only WMC, CBO and DIT tested; skewed Java sample; one company.

Gyimóthy, Ferenc & Siket (2005)

Data
Mozilla 1.6; 3,192 C++ classes matched to Bugzilla reports
Found
CBO is the best predictor. Lines of code come close (R² 0.34 vs 0.43 for all metrics). DIT untrustworthy, NOC unusable.
Limits
One system; size compared, not controlled.

Why it's not settled

Construct“Fault” means four different things across the studies.
InternalClass size drives both scores and faults (El Emam et al., 2001). Only 2 of 4 studies control for it, and they disagree.
ExternalEach study analyses a single system; one uses student code.
ConclusionLogistic regression, linear regression and machine learning give results that are not directly comparable.
CK metrics are not proven valid independent of class size.The study that would settle it: many systems, size controlled, one shared definition of a fault.
